Preguntas Frecuentes

¿Cómo uso esta versión para mi clase?

Haz clic en Comenzar, carga manualmente los participantes y configura el sorteo. Los archivos HTML, CSS y JavaScript se pueden estudiar y modificar por separado.

¿Puedo introducir mis propios números?

Sí. Pega números separados por comas o saltos de línea. También puedes generar una lista indicando un número inicial y uno final.

¿Se conecta con Instagram u otras redes?

Esta práctica funciona con listas manuales. El nombre de usuario o enlace se usa solamente como referencia visual del sorteo; no descarga comentarios ni solicita acceso a tus cuentas.

¿Cómo se eligen los ganadores?

Se mezcla la lista mediante Fisher–Yates usando números generados con crypto.getRandomValues. Los ganadores y suplentes se eligen sin reemplazo entre las entradas elegibles.

¿El resultado es aleatorio?

No. Esta versión tiene el ganador hardcodeado: el último ganador siempre es @olgardz2 y los puestos anteriores se sortean entre el resto. La pantalla y las descargas lo indican.

¿Qué pasa si hay números o nombres repetidos?

Con Eliminar duplicados activado, cada nombre o número participa una vez. Si desactivas esa opción, cada entrada cuenta como una oportunidad y un mismo valor puede aparecer más de una vez en los resultados.

¿Dónde se guarda mi lista?

El borrador permanece en este navegador mediante almacenamiento local. Puedes borrar el borrador desde el formulario. No se envía a un servidor.

¿Puedo descargar el resultado?

Sí. Puedes descargar una imagen PNG, un archivo CSV o copiar el texto con los ganadores de tu sorteo.

¿Es el sitio oficial de AppSorteos?

Es una recreación independiente para estudiar HTML, CSS y JavaScript. La marca y el diseño de referencia pertenecen a AppSorteos.

¿Qué es App Sorteos?

La referencia para esta práctica es una plataforma de sorteos con herramientas para elegir participantes en redes sociales. Esta versión reproduce su lenguaje visual y adapta el flujo a una lista cargada a mano.

El proyecto permite practicar maquetación adaptable, eventos, formularios, validación, almacenamiento local, animaciones y selección aleatoria con JavaScript.
